## SEO & Naming Standard (2026 Premium)
- **URL Strategy**: Transitioned from generic filenames to high-intent, keyword-rich URLs with functional suffixes.
- **Series Overview (Collection)**: `*-collection.html` (e.g., `motorized-retractable-pergola-r230-collection.html`).
- **Product Details (Specs)**: `*-specs.html` (e.g., `motorized-retractable-pergola-r230-specs.html`).
- **Kitchen PDPs**: Descriptive prefixes (e.g., `modular-outdoor-kitchen-station-bre-lite.html`).
- **Catalog/Gallery**: Optimized names like `aluminum-pergola-product-catalog.html` and `outdoor-pergola-projects-gallery.html`.
- **Integrity**: 100% synchronization of internal links, canonical tags, and `sitemap.xml` for all new URLs.
